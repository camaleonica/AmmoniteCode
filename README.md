# Ammonite Code

Proyecto de código experimental y creativo. Con el objetivo de hechar un lindo vistazo al trasfondo de la sagrada geometría en las cosas y retratar perspectivas de todas las posibilidades. Somos esto.

## 🚀 Tecnologías

- React
- p5.js
- Three.js
- Vite

## 🎨 Características

- **Matrix Rain**: Lluvia de caracteres estilo Matrix con colores rosas
- **Imagen a ASCII**: Convierte imágenes a arte ASCII
- **Patrones**: Genera patrones ASCII animados
- **Dibujador**: Dibuja y crea arte ASCII interactivo

## 📦 Instalación

```bash
npm install
```

## 🏃 Ejecutar

```bash
npm run dev
```
